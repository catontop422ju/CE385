1. getNames (ใช้ .map): หน้าที่คือ "ดึงของ" ไปดึงเอาเฉพาะชื่อของทุกคนออกมาต่อกันเป็น Array ใหม่
2. getPassedStudents (ใช้ .filter): หน้าที่คือ "คัดกรอง" เก็บไว้เฉพาะคนที่คะแนนถึง 50 คนไหนไม่ถึงโดนตัดทิ้ง
3. getTotalScore (ใช้ .reduce): หน้าที่คือ "บวกสะสม" จับคะแนนของทุกคนมารวมกันเป็นตัวเลขก้อนเดียว
4. getAverageScore: นำผลรวมจากข้อ 3 มาหารด้วยจำนวนเด็ก (มีบรรทัดดักไว้ว่า ถ้าไม่มีเด็กเลยให้ตอบ 0 เพื่อกันโปรแกรมแจ้ง Error)
5. countByGrade (ใช้ .reduce): เริ่มจากสร้าง "กล่องว่าง {}" แล้วเอาเด็กมาใส่ทีละคน ถ้านับเกรดไหนครั้งแรกให้เริ่มที่ 1 ถ้าเจอเกรดเดิมซ้ำก็บวกเพิ่มทีละ 1
6. getTopStudent (ใช้ .reduce): หน้าที่คือ "หาแชมป์" จับเด็กมาเทียบกันทีละคู่ ใครคะแนนเยอะกว่าก็ชนะและถูกถือไว้ไปสู้กับคนถัดไปจนจบแถว

<!-- ส่วนที่2 -->
ท่อที่ 1: .filter(...) (คัดกรอง)

เรากรองเอาเฉพาะเด็กที่เรียนสาขา "CE" และ (&&) มีคะแนน >= 50 (สอบผ่าน) เท่านั้น คนอื่นที่ไม่ได้เข้าเงื่อนไขนี้จะถูกตัดทิ้งไป

ท่อที่ 2: .map(...) (แปลงโฉม)

ตอนนี้เรามีข้อมูลเด็ก CE ที่สอบผ่านทั้งก้อน (มีทั้งชื่อ สาขา คะแนน) แต่เราจะใช้แค่ตัวเลขไปคำนวณ ท่อนี้เลยดึงออกมาเฉพาะ "ตัวเลขคะแนน" ล้วนๆ

ท่อที่ 3: .reduce(...) (ยุบรวมเป็นค่าเฉลี่ย)

นำตัวเลขคะแนนเหล่านั้นมาบวกสะสมรวมกัน (sum) และหารด้วยจำนวนเด็กทั้งหมดที่กรองมาได้ (arr.length) ไปพร้อมๆ กัน เพื่อให้ออกมาเป็น "คะแนนเฉลี่ย" ในขั้นตอนเดียวครับ

<!-- ส่วนที่3 -->
เมื่อเรานำข้อมูลที่เป็นกล่องเปล่า [] ไปใช้งาน:

คำสั่ง .map() และ .filter() จะฉลาดพอที่จะคืนค่ากล่องเปล่า [] กลับมาให้เลยโดยไม่ Error

แต่สำหรับ .reduce() ถ้าเจอ Array ว่าง มันจะพัง (Error) ทันที ยกเว้นแต่ว่าเราจะกำหนด "ค่าเริ่มต้น" เอาไว้ให้มัน

นี่คือเหตุผลที่ในส่วนที่ 1 เราต้องใส่ตัวเลข 0, กล่อง {} หรือ null ไว้ที่ด้านหลังสุดของคำสั่ง .reduce() เสมอ เพื่อให้มันมีค่าสำรองส่งกลับมาเวลาที่หาข้อมูลไม่เจอนั่นเอง
