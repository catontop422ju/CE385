<!-- ส่วนที่ 1: สร้างฟังก์ชัน Promise (fetchStudentByIdAsync) -->

เปลี่ยนรูปแบบ: เปลี่ยนจากการรับฟังก์ชัน callback มาเป็น return new Promise((resolve, reject) => ...)

ดักจับเงื่อนไข: ถ้า ID ไม่ถูกประเภทหรือว่างเปล่า จะเรียก reject(Error) ทันที

คืนค่าสำเนา: เมื่อหาข้อมูลเจอ จะส่งสำเนาวัตถุด้วย Spread Operator { ...student } ผ่าน resolve เพื่อไม่ให้กระทบข้อมูลต้นฉบับ

<!-- ส่วนที่ 2 และ 3: การต่อโซ่ (Chaining) 3 ชั้น และการทดสอบ 3 กรณี -->

โซ่ชั้นที่ 1 (.then): รับวัตถุ student มาคำนวณเกรด แล้ว return { name, grade } ส่งต่อไปชั้นถัดไป

โซ่ชั้นที่ 2 (.then): รับข้อมูลชื่อและเกรด มาประกอบเป็นข้อความรายงาน แล้ว return ส่งต่อ

โซ่ชั้นที่ 3 (.then): รับข้อความรายงานมาพิมพ์แสดงผลด้วย console.log()

.catch() & .finally(): ดักรับข้อผิดพลาดทั้งหมดเมื่อเกิด reject และสั่งทำงานปิดท้ายเสมอไม่ว่าจะสำเร็จหรือล้มเหลว

การทดสอบ 3 กรณี: ทดสอบด้วย ID ที่มีจริง (สำเร็จ), ID ที่ไม่มีจริง (ล้มเหลวลง catch), และ ID เป็น null (ล้มเหลวลง catch)

<!-- ส่วนที่ 4 (โบนัส): ตัวแปลงอเนกประสงค์ (promisify) -->

สร้างฟังก์ชันครอบ (Wrapper) ที่รับฟังก์ชันแบบ Callback รุ่นเก่า (Error-First) เข้ามา

ดักฟังผลลัพธ์จาก Callback เดิม: ถ้ามี err จะสั่ง reject(err) แต่ถ้าได้ข้อมูลสำเร็จจะสั่ง resolve(result) ทำให้โค้ดรุ่นเก่ารองรับการใช้ .then() และ .catch() ได้ทันที
