<!-- เครื่องมือที่ใช้จำลองการทำงาน

wait(ms, ชื่อ, willFail): เป็นฟังก์ชันจำลองการดึงข้อมูล โดยใช้ setTimeout หน่วงเวลาไว้ตามที่กำหนด ถ้าเราไม่ได้ใส่ค่าพารามิเตอร์ตัวที่ 3 (willFail) มันจะทำงานสำเร็จและคืนค่าผ่าน resolve แต่ถ้าเราแกล้งใส่ true เข้าไป มันจะจำลองว่าระบบล่มและโยน reject ออกมาแทน

timeoutPromise(ms): ฟังก์ชันนี้เราเขียนเพิ่มมาสำหรับข้อ 4 หน้าที่ของมันมีแค่อย่างเดียวคือ "นับถอยหลัง พอครบกำหนดปุ๊บให้โยน Error คำว่า Timeout ออกมาทันที" -->

<!-- โค้ดสถานการณ์ที่ 1: โหลดหน้าแรก (Promise.all) -->

เราส่ง wait ทั้ง 3 ตัวเข้าไปใน Array แล้วครอบด้วย await Promise.all(...)

กรณีสำเร็จ: ถ้าโหลดผ่านหมด มันจะคืนค่ากลับมาเป็น Array ของชื่อ (["โปรไฟล์", "ตารางเรียน", "ประกาศ"]) เราเลยเอามาต่อกันเป็นข้อความเดียวด้วยคำสั่ง .join(", ")

กรณีพัง: ในโค้ดท่อนที่สอง เราตั้งใจให้ "ประกาศ" มีค่า willFail = true พอ Promise.all เห็นว่ามีตัวหนึ่งโยน reject ออกมา มันจะยกเลิกการทำงานทั้งหมดทันที แล้วกระโดดข้ามไปเข้าบล็อก catch(err) ทันทีโดยไม่สนใจตัวที่เหลือ

<!-- โค้ดสถานการณ์ที่ 2: แจ้งเตือน (Promise.allSettled) -->

จุดสังเกตคือ ส่วนนี้ไม่มีการใช้ try-catch เพราะ Promise.allSettled จะไม่โยน Error ออกมาให้โปรแกรมพัง แม้จะมีบางช่องทางส่งไม่ผ่านก็ตาม

พอมันรอจนครบ 3 ตัวเสร็จ มันจะคืนค่าผลลัพธ์มาเป็น Object ที่บอกสถานะแทน เราเลยต้องใช้ .forEach() วนลูปเช็คทีละตัวว่า r.status === "fulfilled" (สำเร็จ) หรือเปล่า ถ้าสำเร็จให้ดึง r.value มาพิมพ์ แต่ถ้าพัง (rejected) ก็ให้ดึง r.reason.message มาแสดงแทน

<!-- โค้ดสถานการณ์ที่ 3: Mirror Server (Promise.any) -->

เราโยน mirror-A (พังที่ 300ms) และ mirror-B (สำเร็จที่ 600ms) เข้าไปทำงานพร้อมกัน

แม้ mirror-A จะทำงานเสร็จก่อนและพังตอน 300ms แต่ Promise.any จะ "เมิน" Error ตัวนี้ทิ้งไปเงียบๆ (ไม่กระโดดเข้า catch) แล้วก้มหน้ารอต่อไป จนกระทั่งเจอ mirror-B ที่โหลดสำเร็จตอน 600ms มันถึงจะคายข้อมูลของ B ออกมาให้เราใช้งานต่อ (คำสั่งนี้จะเข้า catch ก็ต่อเมื่อพังเรียบทุกตัวเท่านั้น)

<!-- โค้ดสถานการณ์ที่ 4: ฐานข้อมูล แข่งกับ Timeout (Promise.race) -->

เราสั่งให้ Promise 2 ตัววิ่งแข่งกัน คือตัวดึงฐานข้อมูล (1200ms) กับตัวจับเวลา (800ms)

ผลคือตัวจับเวลา 800ms เข้าเส้นชัยก่อน และตัวมันเองถูกเขียนมาให้โยน Error Promise.race เลยยึดผลลัพธ์ของคนที่ชนะ ตัดจบการแข่งทั้งหมด แล้วกระโดดเข้า catch ทันที

ข้างใน catch เราจึงเอา if (err.message === "Timeout") มาดักไว้ ว่าถ้าพังเพราะหมดเวลานะ ให้แสดงข้อความว่า "ใช้แคชเก่าแทน"
